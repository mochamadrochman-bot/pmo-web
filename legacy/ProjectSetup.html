Template plan proyek (Excel)

Bobot bidang, plan kumulatif mingguan dan rencana bulanan diisi lewat satu file Excel, lalu diunggah. Hasilnya tampil di bagian 3 dan 4.

1
Unduh templateDibuat dari kode proyek, tanggal mulai–selesai dan MAX_WEEK di bagian 1–2. Isian yang sudah tersimpan ikut terisi.
2
Isi di ExcelSheet BOBOT, PLAN_MINGGUAN (% kumulatif per bidang) dan PLAN_BULANAN (otomatis dari mingguan, boleh ditimpa, plus milestone).
3
Unggah & periksaIsian dibaca dan diperiksa. Bila lolos, bagian 3 dan 4 terisi; simpan proyek seperti biasa.
Tarik file template .xlsx ke siniatau pilih file dari komputer

Plan bulanan proyek ini terhubung ke data mingguan (formula), jadi hanya bisa dilihat. Milestone fisik tetap bisa diubah.
Terisi dari sheet PLAN_BULANAN. Koreksi kecil boleh langsung di tabel.
